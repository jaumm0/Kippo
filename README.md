# Kippo

Site institucional da **KIPPO** — desenvolvimento de landing pages, sites institucionais, sistemas web e automação.

## Stack
- HTML, CSS e JavaScript puro (sem frameworks)
- Tipografia Inter
- Paleta verde esmeralda / grafite
- Bilingue (PT/EN) com troca de idioma em tempo real
- Totalmente responsivo

## Estrutura
- `index.html` — marcação e conteúdo
- `styles.css` — estilos
- `script.js` — interações + dicionário i18n (PT/EN)

## Como rodar localmente
Abra o `index.html` no navegador. Nenhuma dependência ou build é necessária.
